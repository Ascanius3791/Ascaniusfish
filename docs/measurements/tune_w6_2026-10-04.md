# Weight set 6: the fit with the new terms (#90)

```
make tools/tune
```

## Data: `data/tune2`

The #86 recipe on more games: CCRL 40/15 whole, plus CCRL Blitz, CCRL 40/2, CEGT (40/4,
40/20, 40/20 ponder on, 40/120, 5'+3") and TCEC. Both engines ≥3000, at least 40 plies,
duplicates across archives dropped (3.94M games read). Balanced per mean-Elo band, 1,083,300
games, 1,021,627 positions per result:

| split | positions |
|---|---|
| train | 2,455,995 |
| valid | 304,770 |
| test | 304,116 |

It already holds every CCRL 40/15 game, so it is fitted alone: adding `data/tune` would put
the same games on both sides of the split. Only read locally, not committed; CCRL and CEGT
give no licence, TCEC is CC BY-SA.

## Result

K = 302.22, fitted on set 5. 564 s for 1500 epochs (4 threads), peak 681 MB RSS (the leaner
features of 678501b, ~280 bytes per train or valid position). The model the tuner
differentiates matches `basic_eval()` on set 5 to 1.03 cp on average, 12 cp at most.

| set | train | valid | test |
|---|---|---|---|
| 5 | 0.118530 | 0.118667 | 0.118623 |
| 6 | 0.114630 | 0.114748 | 0.114560 |

Valid and test fall together (−0.0039 and −0.0041). These losses are on `data/tune2`, not
comparable with the `data/tune` numbers of earlier sets. 967 of 1065 weights changed; the
model's valid loss had stopped moving by epoch 500.

|---|---|---|

Threats (per attacked enemy piece; pawn rook knight bishop queen): by a pawn −15 15 7 −8 −10,
by a knight or bishop −8 71 68 55 56, by a rook −33 −5 7 13 41; hanging 26. Only the minors'
threats on pieces are clearly large. The pawns' are near zero, perhaps because the positions
are quiet ones, where a pawn threat has usually been answered.

Piece values (opening / endgame, set 5 → set 6): pawn 140 / 136 → 192, knight 468 → 374 /
452 → 586, bishop 579 → 454 / 559 → 660, rook 858 → 589 / 829 → 1098, queen 1642 → 1571 /
1586 → 1870. Every opening value falls and every endgame value rises; the bishop's lead over
the knight shrinks from 111 to 80 in the opening, with the bishop pair now its own term.
The endgame passer values on ranks 2–4 grow by 47–62. The full list is at the end of
`weights/w6.txt`.
