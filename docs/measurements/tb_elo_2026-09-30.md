# Elo added by the tablebases (#41)

Commit 38e145b (working tree, both sides the same build). B = with tables, A = without.
Run from the repo root after `make tools/match`: `tools/match . . tc=5+0.05 openings=<suite> optionsB="SyzygyPath=$HOME/syzygy-nr,SyzygyProbeLimit=5"`.

Tables: `~/syzygy-nr`, probe limit 5, TT `tt=11`, 5 s + 0.05 s per game. Every game ended `Termination "normal"` (no time forfeits, crashes or rules infractions).

| Suite | Games | W / D / L (B) | Score | Elo B−A (95% CI) |
|---|---|---|---|---|
| `tools/endgames.epd` (200 positions, 6–8 pieces, \|cp\| ≤ 150) | 400 | 80 / 297 / 23 | 57.1% | **+49.8 ± 13.6** [+36.4, +63.5] |
| `tools/openings.epd` (100 openings) | 200 | 82 / 41 / 77 | 51.2% | +8.7 ± 42.6 [−33.8, +51.4] |

- Endgames: the tables are worth about +50 Elo, clearly above 0. Only ≤5 piece positions are covered, so this comes from games reaching 5 pieces and from trades into them.
- Openings: the interval includes 0, so probing costs nothing measurable. 200 games only exclude a loss larger than about 34 Elo.

The suite is rebuilt with `make tools/make_endgames`, then `tools/make_endgames tools/endgames.epd count=200` (self-play from the openings, judged by Stockfish 15 at depth 18; the Lichess cloud eval has almost nothing on such positions).
