# TD(λ) targets for the weight fit: sweep and SPRTs (#115)

Commit 02a0310 (`tools/tune td=`), 2026-10-25, local machine (8 cores). Every fit from
`weights/w8.txt` on `data/tune2`, gn, gauge=pin, lambda 1e-9, K 293.32 (fitted on set 8):

```
./tools/tune data=<repo>/data/tune2 from=weights/w8.txt out=td<λ>.txt jobs=4 se=0 td=<λ> rounds=8
```

`td=1` is checked against main's tuner: 2 steps from w8, identical set files.

## Sweep

Positions per game in tune2's train: 3 for 735k games, 2 for 119k, 1 for 12k, so a chain
has at most 2 bootstrap steps. The rounds converge fast: the targets move 0.055 on average
in round 1 (TD(0.7)), 0.0012 in round 2, 0.00006 in round 3.

| td | rounds | valid loss to targets | real eval, loss to results (train / valid / test) | changed | Q / R / N / B opening |
|---|---|---|---|---|---|
| 1 (w9, `weights/w9.txt`) | 1 | 0.113312 | 0.113226 / 0.113309 / 0.113176 | 787 | 1316 / 445 / 388 / 426 |
| 0.9 | 3 | 0.099667 | 0.113231 / 0.113311 / 0.113174 | 804 | 1314 / 440 / 382 / 420 |
| 0.7 | 3 | 0.079328 | 0.113273 / 0.113343 / 0.113202 | 849 | 1312 / 428 / 370 / 407 |
| 0.5 | 4 | 0.066218 | 0.113370 / 0.113431 / 0.113289 | 901 | 1310 / 416 / 358 / 395 |
| 0.3 | 4 | 0.058439 | 0.113485 / 0.113543 / 0.113388 | 914 | 1308 / 405 / 346 / 382 |
| 0 | 5 | 0.054127 | 0.113741 / 0.113782 / 0.113625 | 908 | 1305 / 388 / 327 / 363 |

w8: 0.113333 / 0.113429 / 0.113289, Q / R / N / B 1449 / 483 / 415 / 455.

The loss to results rises as td falls, by design: a TD fit is not trying to predict the
result. So no static loss can pick the best td, only games. The main effect of lower td is
that the minor pieces and the rook lose opening value (the knight 388 → 327 from td 1 to 0).
The queen and the endgame values hardly depend on td.

## Long chains: 16 positions per game (`chain=`)

Commit 4698a74. `tools/tune_data chain=1` wrote 16 positions per game of tune2's games
(`data/tune_chain16/chain.tsv`, 15.5 M positions of 1.08 M games, 1.03 GB, 50 min). They
are only bootstrap points: their eval enters the λ-returns, the fit positions stay tune2's.

```
./tools/tune data=<repo>/data/tune2 from=weights/w8.txt out=c<λ>.txt jobs=6 se=0 td=<λ> rounds=8 \
    chain=<repo>/data/tune_chain16/chain.tsv
```

11.8 M train / 1.47 M valid chain positions, 832 MB peak, 5–7 min per round (reading the
chain and `make_pos` on it each round). Without `chain=` the tuner reproduces the td 0.7
set above exactly.

| td | rounds | time | valid loss to targets | real eval, loss to results (train / valid / test) | changed | Q / R / N / B opening |
|---|---|---|---|---|---|---|
| 0.97 | 3 | 17 min | 0.081833 | 0.113249 / 0.113321 / 0.113180 | 851 | 1309 / 427 / 371 / 409 |
| 0.9 | 5 | 30 min | 0.045807 | 0.113457 / 0.113502 / 0.113357 | 898 | 1299 / 392 / 337 / 374 |
| 0.8 | 7 | 43 min | 0.027170 | 0.113896 / 0.113919 / 0.113761 | 920 | 1292 / 357 / 300 / 338 |

As with the short chains, the minor pieces and the rook fall with td. All three cut the
queen to ~1300 (w8 1449). td 0.97 is the only TD set that beats w8 on the loss to results.
