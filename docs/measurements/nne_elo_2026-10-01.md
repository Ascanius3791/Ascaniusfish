# Elo added by the eval-correction net (#53)

Commit 3a7aef7, one binary for both sides (`ascaniusfish_uci.cpp` built with
the flags `tools/match` uses and `-DTT_EXPONENT=11`). B = `UseNNE=true` with
`nets/nne_d6.bin` (the net of `nne_train_2026-10-01.md`, correction at the quiet
leaf of `minimax_tactical` only), A = off. Run from the repo root after
`make tools/match`:

```
tools/match <bin> <bin> tc=5+0.05 openings=tools/openings.epd \
    optionsB="NNEFile=$PWD/nets/nne_d6.bin,UseNNE=true"
```

`NNEFile` is absolute because a net that fails to load only gives an info string
and the engine plays on without it. The same binary with the same options, run
from `/tmp`, answers `info string nne on, <path>`.

5 s + 0.05 s per game, 7 games in parallel, 376 s. All 200 games ended
`Termination "normal"` (no time forfeits, crashes or rules infractions).

|---|---|---|---|---|

- The interval is above 0 after the first 200 games, so no more were played and
  none of the fallback variants (`NNE_DESIGN.md`) was needed.
- Both sides reach the same depth on average (A 7.34, B 7.36, over ~13.9k moves
  each). The net costs about 16% nps (`nne_nps_2026-10-01.md`), but the search
  needs fewer nodes per depth with it (startpos after 1.e4 e5 2.Nf3, depth 8:
  129,581 nodes on, 188,925 off), so the time to a given depth is about the same.
