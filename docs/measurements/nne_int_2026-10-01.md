# NNE in integers: cost, exactness and Elo (#55), 2026-10-01

Commit 328d3b4 (int16 first layer updated per leaf, int16 × int16 → int32 second
layer, AVX2 chosen at run time) against main's float32 net (ec12ce5), both with
`nets/nne_d6.bin`. i7-1065G7 under WSL2.

## Cost per node: `perf stat`, the method of `nne_nps_2026-10-01.md`

`tools/bench 7` minus `tools/bench 1` (startup), `instructions:u` and
`cycles:u`, pinned to one core. The clock drifts too much between runs for
single numbers, so each round runs UseNNE off and on back to back and the
round's on/off ratio is taken; the cost is the median ratio over the rounds.

| Build | Rounds | instructions/node off → on | cycles/node, median cost | min / max |
|---|---|---|---|---|
| main (float, recomputed) | 10 | 4413 → 5001 (**+13.3%**) | **+14.6%** | +2.4% / +29.8% |
| 328d3b4 (int, updated)   | 12 | 4411 → 4509 (**+2.2%**)  | **+2.7%**  | −5.4% / +7.8% |

The two builds were measured in separate sets; an earlier draft measured in
both gave +4.2% and +4.3%, so the sets agree. The update touches 4.8 first-layer
rows per leaf on average in `make bench`, and 3.7% of leaves start from scratch.
A per-ply stack fed by the search (an `ascaniusfish_2.hpp` patch) would save
about one more row per leaf, ~0.15% of a node, so it was not proposed.

## Exactness: `make nne-test`

All 53176 positions of `nets/nne_d6_test.tsv`: largest difference between the
engine's correction and the trainer's **0.24 cp** (limit 1 cp; the float build
had 0.00008 cp). The updated first layer equals one computed from scratch bit for
bit over 1749683 positions, and AVX2 equals the generic code bit for bit.
`make bench` is unchanged with the net off (48039); with `NNE=nets/nne_d6.bin`
it goes 48985 → 49013, since the rounded correction changes a few leaves.

## Elo: int vs float, 5+0.05

Both engines built with `tools/match`'s flags and `-DTT_EXPONENT=11`, A = main
(float), B = 328d3b4 (int), both `NNEFile=<abs path>,UseNNE=true`:

```
tools/match uci_main uci_int tc=5+0.05 openings=tools/openings.epd \
    optionsA="NNEFile=$N,UseNNE=true" optionsB="NNEFile=$N,UseNNE=true"
```

Run twice over the 100 openings (timing makes the passes differ), 7 games in
parallel, 357 s + 373 s. All 400 games ended `Termination "normal"`.

| Games | W / D / L (B) | Score | Pairs 0/½/1/1½/2 | Elo B−A (95% CI) |
|---|---|---|---|---|
| 200 (pass 1) | 81 / 49 / 70 | 52.8% | 9 / 16 / 47 / 11 / 17 | +19.1 ± 39.1 |
| 200 (pass 2) | 85 / 47 / 68 | 54.2% | 9 / 14 / 41 / 23 / 13 | +29.6 ± 38.1 |
| **400** | 166 / 96 / 138 | 53.5% | 18 / 30 / 88 / 34 / 30 | **+24.4 ± 27.2** [−2.7, +51.7], LOS 96% |

The int build loses nothing; if anything it gains, as the cheaper node buys
depth: average reached depth 7.35 (B) against 7.18 (A) over ~26.6k moves each,
at the same 0.091 s per move.
