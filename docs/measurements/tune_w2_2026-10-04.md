always measured with the real `basic_eval()` and the rounded weights.

## Result

K = 329.79, fitted once on set 1 and held. Full fit: 243–262 s wall (1500 epochs, 4 threads
on WSL), peak 569 MB RSS.

| set | train | valid | test |
|---|---|---|---|
| 1 | 0.140723 | 0.140784 | 0.141126 |
| 2 | 0.125280 | 0.125418 | 0.125862 |

Valid and test fall together (−0.0154 and −0.0153), so the fit is not specific to the training
positions. 786 of 842 weights changed. Set 2 loads with `setoption name WeightsFile value
weights/w2.txt` (provenance `weights 2`), and `king_safety_test weights/w2.txt` passes, the
`king_safety_eval` and `basic_eval` mirror-symmetry checks at 0/4000 broken.

The model of `basic_eval()` the tuner differentiates matches the real eval on set 1 to 1.0 cp
on average, 8 cp at most (integer truncation).

## The L2 pull toward set 1 (λ)

Every λ beats set 1. 600-epoch runs, valid loss:

| λ | valid | weights |
|---|---|---|
| 1e-7 | 0.13311 | close to set 1 (stalls after ~150 epochs) |
| 1e-8 | 0.12884 | |

λ=1e-9 is the default: λ=0 fits best but its rarely seen squares look overfitted. Whether a
larger λ plays better is for #88's match to say; set 1 stays the default set.
