## nps cost: `tools/bench 7 [nne=nets/nne_d6.bin]`

Wall-clock nps swung 4x between identical runs (412k to 1.81M, the clock
changes speed), so cost is measured with `perf stat` per node, depth 7 minus
depth 1 (startup):

| | nodes | instructions/node | cycles/node |
|---|---|---|---|
| UseNNE off | 1746127 | 4412 | 2075, 2065, 2716 |
| UseNNE on  | 1727514 | 5000 | 2466, 2445, 2576 |

**+13% instructions and about +19% cycles per node, so about 16% fewer nps**
(the third round's net-off run is noisy and left out). One correction costs
about 1.7k cycles (~0.5-0.8 us). Most of that is the first layer
waiting on ~10 kB of W1 rows from L2 (21 active inputs x 512 B), not the
arithmetic, so an incrementally updated first layer is the fix if #53 finds
the cost too high.

Two code-generation traps, both avoided in `src/nne.cpp`: GCC unrolled the
loop over active inputs by two and fused the pair into a scalar loop (so the
layers are written with vector types), and skipping first-layer units clipped
to 0 mispredicts about half the time (so layer 2 does not branch). Together
they took one correction from ~4000 to ~1700 cycles.
