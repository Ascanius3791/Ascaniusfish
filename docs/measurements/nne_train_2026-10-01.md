# NNE training: the net beats a constant correction on unseen games (#51)

Commit 7c76234 (`tools/nne_train`, built by `make tools/nne_train`), on the
dataset of `docs/measurements/nne_data_2026-09-30.md` (train 426,371, valid
53,355, test 53,176 positions, split by game). Design: `docs/NNE_DESIGN.md`.

```
./tools/nne_train frac=1                         # writes nets/nne_d6.bin, nets/nne_d6_test.tsv
./tools/nne_train frac=0.5  out=- preds=-
./tools/nne_train frac=0.25 out=- preds=-
```

780 → 128 → 16 → 1, clipped ReLU, loss `log(|static + c − label| + 50)`, AdamW
(lr 1e-3, weight decay 1), batch 1024, seed 51, on the GPU (MX350, CUDA). The
learning rate halves after 3 epochs without a better validation loss, training
stops after 8, and the best epoch's weights are kept. The full run takes 206 s
(60 epochs, about 3.4 s each). Two trainers at once slow each other to about
13 s an epoch, so run them one at a time.

## Test set (errors are |label − prediction|, cp)

| prediction | median | mean, clipped at 1000 | loss |
|---|---:|---:|---:|
| **static + net** | **57.95** | **136.76** | 4.8887 |
| static + mean training correction (+14.58 cp, mover's view) | 68.42 | 146.57 | 4.9532 |
| static | 68.00 | 146.67 | 4.9532 |

So the net takes 15% off the median error and 7% off the clipped mean.
The constant correction is no better than none: the mean (+14.6 cp) is pulled by
the tails, while the median correction is +8.

## Learning curve (weight decay 1, the same validation and test sets)

| training positions | best epoch | test median | test clipped mean | test loss |
|---:|---:|---:|---:|---:|
| 106,593 (25%) | 27 | 62.16 | 140.08 | 4.9135 |
| 213,186 (50%) | 37 | 59.56 | 138.05 | 4.8989 |
| 426,371 (100%) | 52 | 57.95 | 136.76 | 4.8887 |

Each doubling still gains about 2 cp of median. The curve has not flattened, so
more positions (a further Lichess month, see the design's "Data") should
help.

## Weight decay (100% of the training set, chosen on validation only)

| weight decay | best epoch | valid loss | valid median | valid clipped mean |
|---:|---:|---:|---:|---:|
| 0 (Adam) | 10 | 4.8934 | 59.98 | 135.92 |
| 0.01 | 14 | 4.8934 | 59.88 | 135.72 |
| 0.1 | 14 | 4.8916 | 59.62 | 135.59 |
| 0.3 | 22 | 4.8905 | 59.46 | 135.38 |
| **1** | 52 | **4.8865** | **57.75** | 135.84 |
| 3 | 135 | 4.9074 | 60.59 | 139.87 |

Without decay the net overfits after about 10 epochs (training loss keeps
falling, validation loss does not). Weight decay 1 is now the trainer's default.
Without decay the test numbers were 60.08 / 137.21 (25%: 63.18 / 140.69,
50%: 61.23 / 139.49).

## Export

`nets/nne_d6.bin`, 408,224 bytes (layout in `docs/NNE_DESIGN.md`).
`nets/nne_d6_test.tsv` has all 53,176 test positions with the net's
correction. A separate plain-C++ forward pass over the file (the sparse
first layer, as the engine will run it) on `test.tsv`'s features matches
the trainer's predictions to within 0.00008 cp.
