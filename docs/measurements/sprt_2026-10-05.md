# SPRT in tools/match, sanity runs (#92)

Base 751fd80 plus the #92 working tree. Engine: `ascaniusfish_uci` built once with
`-DTT_EXPONENT=17`, used as both A and B. Every run is `sprt=0,10` (logistic Elo,
α = β = 0.05, LLR bounds ±2.94) on `tools/openings_ccrl.epd`, 4 games in parallel.

The "no material" engine is the same binary with `WeightsFile=` set to `weights/w6.txt`
with `piece_value` and `piece_value_endgame` all 0 (the piece-square tables still
carry some material). The net is off on both sides (`UseNNE=false`), so it can't
put the material back.

## Why the LLR is not the normal approximation

The issue's notes suggested cutechess/fastchess's LLR = n(s1−s0)(2m−s0−s1)/(2v). Its first
run accepted H1 after a single 2–0 pair (LLR +3.79): one pair gives no variance beyond the
1e-3 regularization. The LLR is now fishtest's generalized SPRT (the maximum-likelihood
pentanomial distribution under each hypothesis). Both computed on the same counts:

| pairs (0/½/1/1½/2) | maximum likelihood | normal approximation |
|---|---|---|
| 10 50 80 50 10 | −0.368 | −0.368 |
| 8 45 80 55 12 | +0.786 | +0.790 |
| 5 40 80 60 15 | +2.230 | +2.292 |
| 0 0 0 0 1 | +0.028 | +3.790 |
| 0 0 0 0 10 | +0.284 | +378.2 |
| 0 0 5 0 0 | −0.140 | −4.143 |
